## Project Overview

This project was developed for the "Semana de Marte" Web Hackathon. The objective of the challenge is to design and build a creative 404-themed web experience inspired by the Mars concept.

## **Technologies Used**

- **HTML5** – Structure and semantic markup
- **CSS3** – Animations, visual effects, responsive design
- **JavaScript (Vanilla)** – Interactivity, meteor and astronaut animations, fragment dynamics, scan effect
- **Canvas API** – Animated starfield background

---

## **Features**

- **Dynamic 404 Scene**: A full-screen space environment with Mars, meteor, and stars.
- **Interactive Astronaut**: Drag and move the astronaut around the screen.
- **Cinematic Meteor Impact**: Meteor falls, fragments explode dynamically, shockwave effect covers the screen with a red tint while stars remain visible.
- **Fragment Animations**: Both the meteor and Mars produce fragments that fly in random directions to enhance visual drama.
- **Floating Spaceship**: Detailed spaceship with cockpit, wings, engine flames, and blinking lights floats subtly in the background.
- **Rescan Space Button**: Triggers a scan animation and resets the astronaut and meteoroid positions, allowing the scene to replay.
- **Responsive Design**: Works on both desktop and mobile screens.

---

## **How to Run Locally**

1. Clone the repository:

```bash
git clone https://github.com/kiibs/404-to-mars.git
```

2. Open `404.html` in your preferred browser.
3. Interact with the astronaut by clicking and dragging.
4. Click **Rescan Space** to replay the meteor impact sequence.

## **Design & Inspiration**

- **Mars Theme**: Inspired by the “Semana de Marte” challenge. The planet is large and visually detailed with craters and explosion effects.
- **Space Drama**: Meteor impact, fragments, and shockwave create tension and visual storytelling.
- **Interactivity**: The user can control the astronaut to explore the scene, enhancing engagement.
- **Spaceship Detail**: Added simple cockpit, wings, and engine flames for a more immersive space environment.
- **Aesthetic Choices**: Dark space background with a moving starfield, red shockwave overlay, and glowing elements to maintain a sci-fi feel.
